Need to know

Frequently asked questions

Are pieces produced in small batches?

Yes. The catalogue stock is intentionally finite so students can see the API and checkout guard inventory.

Is this a real payment flow?

No. The lesson stops at a dummy confirmed order and never collects card details.

Can I change the frontend?

Absolutely. Start on the student branch, run the milestone checks, and use the reference branch whenever you need a working comparison.

Where does the data live?

Products, users and orders live in Cloudflare D1 behind a Hono Worker. The browser only keeps the cart locally.
